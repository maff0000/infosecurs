# Foundations terminology reference

Short, plain-English explanations this skill may draw on. These are
reference notes for IRENE's own answers - never shown to the customer
verbatim as a substitute for the real question copy.

- **Multi-factor authentication (MFA)**: proving who you are with more
  than one thing - typically a password plus a one-time code or approval
  on a phone. Reduces the damage a stolen password alone can do.
- **Endpoint protection**: software on a laptop/device that looks for and
  blocks malware. Not the same as a firewall.
- **Joiner/mover/leaver (JML)**: the process for giving someone access
  when they join, changing it when their role changes, and removing it
  when they leave.
- **Not sure**: a legitimate answer. It means the fact is not yet
  confirmed - it is recorded as unknown, never silently treated as "yes".
